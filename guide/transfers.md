# 文件传到哪去了

屏幕底部有一条传输进度条，点它可以展开看到所有正在传、排队、已完成和失败的任务。

![传输面板：每个文件传给谁、传了多少、失败原因都在这里](../screenshots/06-transfer-panel.png)

也可以随时按 **Ctrl + J** 打开完整传输面板，在这里可以：

- **暂停 / 继续** 某个任务（点 ▮▮ 或 ▶）；
- **取消** 不需要的传输；
- 一眼看出每个文件传给谁、传了多少、失败原因是什么。

## 为什么同时只传一个文件

两个人之间同时只排一个文件的队，其他的自动排队等前面传完 —— 这样不会互相抢网速，也不会让两边都慢成一片。

想同时传多个，可以**分给不同的人**，或者去 设置 → 传输 调整并发数（默认值对大多数场景够用）。

## 断网了会怎样

- 传到一半断开：恢复连接后**自动从断点继续**，不用从头再来；
- 对方不在线：文件进入队列，对方一上线自动开始；
- 彻底失败：任务留在面板里并写明原因，可以手动重试。

::: tip 接收方下载目录
收到的文件默认放在「下载」文件夹，可以在 设置 → 通用 里改成你习惯的位置。
:::
