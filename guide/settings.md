# 设置里都有什么

点左下角自己的头像 → **设置**（或 `Ctrl + ,`）。

![设置 · 通用：显示名、下载位置、背景图](../screenshots/07-settings-general.png)

| 页面 | 管什么 | 一般要动吗 |
|---|---|---|
| **通用** | 显示名、文件保存位置、背景图 | 会：改下载目录、换背景 |
| **快捷键** | 查看与修改全部快捷键 | 会：见[个性化与快捷键](./personalize.md) |
| **提示与启动** | 开机自启、声音、最小化到托盘 | 常改 |
| **网络** | 端口等网络参数 | 基本不动 |
| **连接与安全** | 加密与连接选项 | 保持默认（认证必须开着） |
| **传输** | 并发数、限速 | 默认够用 |
| **跨网段种子** | 跨楼层的「桥梁」地址 | 跨网段时必配，见[这里](./peers.md) |
| **更新** | 要不要自动更新 | 建议保持开启 |
| **部署自检** | 网络出问题时逐项检查 | 出问题时用，见[部署自检](../deploy/selfcheck.md) |

## 自动更新：从局域网里取新版

蜂群会从**局域网里版本更高的那台电脑**获取新版，全程仍然不连外网。默认行为是「下载完再问我」，弹窗里可以选：

![更新提示：立即更新、稍后、指定时间、放弃本次](../screenshots/11-update-prompt.png)

| 选项 | 结果 |
|---|---|
| **立即更新并重启** | 马上装并重启 |
| **稍后提醒** | 这次不装，过一会儿再问 |
| **选择时间** | 指定今晚 22:00、明天 02:00 这类时间 |
| **放弃本次** | 知道了，但这一版不装 |

::: tip 这也是它不连外网的一部分
更新包同样来自你身边那台电脑，所以在一个封死外网的机房里，软件照样能升级 —— 只要有人把新版本带进来。
:::

## 退出 ≠ 关闭窗口

点关闭按钮只是**隐藏到托盘**（右下角小图标）。真正退出要右键托盘图标 → 退出。

这不是 bug：截图快捷键 `Ctrl + Shift + A` 只有在后台运行时才有意义。
