# 聊天

1. 在左边列表点一个人的名字；
2. 下方输入框打字，按 **Enter** 发送；想换行按 **Shift + Enter**；
3. 每条消息只带时间戳，界面干干净净。

如果发送时对方正好离线，消息会显示「发送失败」并在对方上线后**自动重试**，不用你管。

## 输入框上方的按钮

| 按钮 | 功能 |
|---|---|
| 📎 | 发送文件 |
| 📁 | 发送整个文件夹 |
| 🖼️ | 发送图片（会直接在聊天里显示） |
| 📷 | 截图 |
| 😊 | 表情 |
| 🗑️ | 清空聊天区 |

**清空聊天区不会删消息。** 点 🗑️ 只是把界面清干净，消息还在本机；点聊天区上方的时钟按钮「查看历史」就能全部找回来。

## 发文件

- 点 📎 选文件，或直接把文件**拖进聊天窗口**；
- 点 📁 可以把整个文件夹一次发过去，里面的子文件夹结构会保留；
- 对方不在线也没关系，文件会先**排队**，等对方一上线自动发过去；
- 传了一半断网，恢复后**从断点继续**，不用从头再来；
- 收到的文件默认放在「下载」文件夹，可以在 设置 → 通用 里改。

传输的进度、暂停与失败原因，见[文件传到哪去了](./transfers.md)。

## 截图与标注

1. 点输入框上方的 📷，或按 **Ctrl + Shift + A**（应用在后台时也有效）；
2. 屏幕变暗后，**按住左键拖动**框选要截的区域；
3. 上方工具栏可以加标注，每个工具都有单键快捷键：

| 工具 | 键 | 工具 | 键 |
|---|---|---|---|
| 矩形 | `R` | 文字 | `T` |
| 椭圆 | `E` | 序号标记 | `N` |
| 箭头 | `A` | 马赛克 | `M` |
| 直线 | `L` | 取色 | `I` |
| 画笔 | `P` | 选择 / 调整选区 | `V` |
| 荧光笔 | `H` | | |

4. 按 **Enter** 完成 —— 截图会直接放进聊天输入框，点发送即可；
5. 也可以按 **F3** 只把截图贴到屏幕上自己看，或按 **Ctrl + S** 存成文件；
6. 后悔了按 **Esc** 退出，什么都不发。

::: warning macOS 上第一次截图要授权
需要在「系统设置 → 隐私与安全性 → 屏幕录制」里给蜂群授权，否则可能只截到一张桌面壁纸。
:::

按 **Ctrl + K** 搜索，中文两个字就能搜到。详见[个性化与快捷键](./personalize.md)。
